# Daily apply loop (LinkedIn / Indeed / Unstop / career pages)

## After seeding Vault

1. Open **Knowledge Vault** → **Seed job portals** (adds LinkedIn, Indeed, Unstop, Naukri, Instahyre, Wellfound, Greenhouse, …).
2. Install models if needed (`scripts/install-ollama-models.ps1`) → Canvas → **Ollama**.

## When you find a job on LinkedIn / Indeed / Unstop / Wellfound

1. Copy the **posting URL** (not the search results page).
2. **Jobs → Import** (or paste JD into Tailor / Quick Apply).
3. Run Canvas / Tailor → Approvals → package.
4. Open the employer form (or company Greenhouse/Lever page) → Chrome extension autofill if allowlisted → **you** click Submit.
5. Tracker → Applied; Outreach for follow-up email.

Career OS **does not** silent Easy Apply on LinkedIn or Indeed.

## When you want bulk find

1. **Pipeline** → Scan Vault + boards + web.
2. Approve shortlist → evaluate → prepare → approve apply/email.
3. Finish remaining Review & Apply gates.

## Best autofill targets

Company career pages on **Greenhouse / Lever / Ashby / Workday** — extension allowlist. Prefer “Apply on company site” links from LinkedIn when available.
